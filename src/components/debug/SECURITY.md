# Безопасность дебаг режима

## Защита от обычных пользователей

Дебаг режим полностью скрыт от обычных пользователей в production:

### 1. Проверка окружения
- `import.meta.env.DEV === false` - дебаг режим отключен (production)
- `import.meta.env.DEV === true` - дебаг режим доступен только разработчикам (development)

### 2. Конфигурация безопасности
Файл `src/config/debugConfig.ts` содержит все настройки безопасности:

```typescript
export const DEBUG_CONFIG = {
  // Разрешен ли дебаг режим (только в development)
  isEnabled: import.meta.env.DEV,
  
  // Разрешен ли дебаг режим через URL параметры
  allowUrlParams: import.meta.env.DEV,
  
  // Разрешен ли дебаг режим через localStorage
  allowLocalStorage: import.meta.env.DEV,
  
  // Разрешен ли дебаг режим через горячие клавиши
  allowHotkeys: import.meta.env.DEV,
};
```

### 3. Дополнительная защита через переменные окружения

Создайте файл `.env.local` в корне проекта:

```bash
# Полностью отключает дебаг режим даже в development
VITE_DEBUG_ENABLED=false
```

### 4. Что происходит в production

В production окружении:
- ❌ Дебаг панель не отображается
- ❌ Кнопки дебаг режима не показываются
- ❌ Горячие клавиши не работают
- ❌ URL параметры игнорируются
- ❌ localStorage настройки игнорируются
- ❌ Все дебаг функции отключены

### 5. Проверка безопасности

Для проверки, что дебаг режим отключен в production:

1. Соберите проект: `npm run build`
2. Запустите production версию: `npm run preview`
3. Попробуйте добавить `?debug=true` к URL
4. Убедитесь, что дебаг панель не появляется

### 6. Коммит в production

При коммите в production:
- ✅ Дебаг код остается в коде, но не выполняется
- ✅ Нет дополнительных файлов для удаления
- ✅ Безопасность обеспечивается через проверки окружения
- ✅ Обычные пользователи не видят дебаг функциональность

## Заключение

Дебаг режим полностью безопасен для production и недоступен обычным пользователям.
