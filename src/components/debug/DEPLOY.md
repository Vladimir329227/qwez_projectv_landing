# Инструкция по деплою с дебаг режимом

## 🚀 Как работает автоматическое отключение

### **Development режим:**
```bash
npm run dev
```
- `import.meta.env.DEV = true`
- Дебаг режим **включен**
- Кнопки и панель **видны**

### **Production режим:**
```bash
npm run build
npm run preview
```
- `import.meta.env.DEV = false`
- Дебаг режим **отключен**
- Кнопки и панель **скрыты**
- Код **не выполняется**

## 📦 Что происходит при сборке

### **Vite автоматически:**
1. **Tree-shaking** - удаляет неиспользуемый код
2. **Dead code elimination** - убирает недостижимые ветки
3. **Minification** - минифицирует код

### **Результат в production:**
```javascript
// Вместо этого:
if (import.meta.env.DEV) {
  // дебаг код
}

// Остается только:
// (пусто - код удален)
```

## ✅ Рекомендация: Коммитить как есть

### **Почему НЕ добавлять в .gitignore:**

❌ **Проблемы с .gitignore:**
- Каждый разработчик должен создавать файлы заново
- Легко забыть при клонировании репозитория
- Нарушает принцип "код должен работать из коробки"
- Сложнее поддерживать команду

✅ **Плюсы коммита:**
- Код работает из коробки для всех разработчиков
- Автоматически отключается в production
- Легко поддерживать и обновлять
- Соответствует best practices

## 🔒 Безопасность

### **В production:**
- ❌ Дебаг панель не отображается
- ❌ Кнопки не показываются
- ❌ Горячие клавиши не работают
- ❌ URL параметры игнорируются
- ❌ localStorage настройки игнорируются

### **Проверка безопасности:**
```bash
# 1. Соберите проект
npm run build

# 2. Запустите production версию
npm run preview

# 3. Попробуйте включить дебаг
# Откройте: http://localhost:4173/?debug=true
# Убедитесь: дебаг панель НЕ появляется
```
