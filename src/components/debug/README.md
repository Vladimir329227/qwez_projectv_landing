# Debug Mode для Quiz Navigation

Этот дебаг режим позволяет быстро перемещаться между слайдами квиза для тестирования и разработки.

## Как включить дебаг режим

### Способ 1: URL параметр
Добавьте `?debug=true` к URL страницы квиза:
```
http://localhost:3000/?page=quiz&debug=true
```

### Способ 2: Кнопка в development режиме
В development режиме в правом нижнем углу появится синяя кнопка с эмодзи 🐛. Нажмите на неё для включения/выключения дебаг панели.

### Способ 3: Горячие клавиши
Нажмите `Ctrl+D` (или `Cmd+D` на Mac) для переключения дебаг режима.

## Как отключить дебаг режим

### Способ 1: Через дебаг панель
1. Откройте дебаг панель
2. Нажмите кнопку **"Disable Debug Mode"** (красная кнопка внизу панели)
3. Страница перезагрузится с отключенным дебаг режимом

### Способ 2: Через кнопки в development режиме
- **Синяя кнопка 🐛** - переключение видимости панели
- **Красная кнопка ✕** - скрытие панели (настройка остается)
- **Темно-красная кнопка 🚫** - полное отключение дебаг режима

### Способ 3: Через консоль браузера
Откройте консоль (F12) и выполните:
```javascript
// Полное отключение дебаг режима
localStorage.removeItem('debug-mode');
window.location.reload();
```

### Способ 4: Через URL
Уберите параметр `debug=true` из URL:
```
Было: http://localhost:3000/?page=quiz&debug=true
Стало: http://localhost:3000/?page=quiz
```

### Способ 5: Горячие клавиши
- `Ctrl+D` - переключение видимости панели
- Кнопка **"✕"** в панели - скрытие панели
- Кнопка **"Disable Debug Mode"** - полное отключение

## Возможности дебаг панели

### Навигация
- **Кнопки Prev/Next** - переход на предыдущий/следующий слайд
- **Быстрые кнопки 1-9** - прямой переход к слайдам 1-9
- **Специальные кнопки** - переход к началу, середине или концу квиза

### Информация
- **Текущий слайд** - показывает номер текущего слайда и общее количество
- **Прогресс** - процентное соотношение пройденных слайдов

### Горячие клавиши
- `←` / `→` - переход на предыдущий/следующий слайд
- `1-9` - прямой переход к слайдам 1-9
- `Ctrl+D` - переключение дебаг режима

### Управление панелью
- **Свернуть/развернуть** - кнопка ▲/▼ для минимизации панели
- **Закрыть** - кнопка ✕ для полного скрытия панели

## Сохранение настроек

Настройки дебаг режима сохраняются в localStorage браузера. Если вы включили дебаг режим, он останется включенным при перезагрузке страницы.

## Технические детали

- Дебаг режим работает только на странице квиза (`QuizPage`)
- Кнопка активации видна только в development режиме
- Все настройки сохраняются в localStorage с ключом `debug-mode`
- Панель имеет высокий z-index (50) для отображения поверх всех элементов
