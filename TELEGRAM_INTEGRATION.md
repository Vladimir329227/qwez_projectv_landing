# Интеграция с Telegram для отправки результатов опроса

## Описание

Добавлена функциональность автоматической отправки результатов опроса в Telegram при завершении прохождения квиза.

## Конфигурация

В файле `src/utils/telegramSender.ts` настроены следующие параметры:

```typescript
const TELEGRAM_BOT_TOKEN = "8010738456:AAEoag7AQtUnTAvAzMJVHJ3DYUXnA0b8MO4";
const TELEGRAM_CHAT_ID = "1924632942";
```

## Как это работает

1. **Автоматическая отправка**: При завершении опроса и генерации рекомендаций, результаты автоматически отправляются в указанный Telegram чат.

2. **Формат сообщения**: Сообщение включает:
   - Информацию о пользователе (имя, email, возраст, пол)
   - Профиль здоровья и описание
   - Ключевые преимущества
   - Рекомендуемые продукты с детальной информацией
   - Рекомендации по образу жизни
   - Руководство по использованию
   - Краткую сводку ответов на опрос

3. **Асинхронная отправка**: Отправка происходит асинхронно и не блокирует отображение результатов пользователю.

## Файлы

- `src/utils/telegramSender.ts` - основная логика отправки в Telegram
- `src/hooks/useRecommendations.ts` - интеграция с хуком рекомендаций
- `src/utils/telegramTest.ts` - тестовые функции для проверки

## Тестирование

Для тестирования функциональности можно использовать:

```typescript
import { testTelegramSending } from './src/utils/telegramTest';

// Запуск теста

  console.log('Test result:', success);

```

## Безопасность

⚠️ **Важно**: Токен бота и ID чата хранятся в коде. В продакшене рекомендуется:

1. Вынести эти значения в переменные окружения
2. Использовать серверную часть для отправки сообщений
3. Добавить аутентификацию и авторизацию

## Логирование

Все операции логируются в консоль:
- Успешная отправка: `Quiz results sent to Telegram successfully`
- Ошибки отправки: `Failed to send quiz results to Telegram`
- Ошибки API: детальная информация об ошибке

## Структура данных

Отправляемые данные включают:
- Полные ответы пользователя на опрос
- Сгенерированные рекомендации
- Метаданные (время, информация о пользователе)
- Профиль здоровья и рекомендации
